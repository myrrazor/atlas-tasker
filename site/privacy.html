Privacy

No cookies. No tracking. No account.

This website has no accounts or contact forms. Atlas Tasker keeps project data in your repository. The local app may set one essential loopback session cookie; this marketing site sets none.

Last updated September 14, 2026

What this site collects

Nothing through the page itself. The site sets no cookies and runs no analytics, ad pixels, session replay, contact form, or third-party embed. There are no accounts and no payments. There is no cookie banner because there is nothing to consent to.

Loading a website sends your IP address and request information to its hosting provider. Following a GitHub link uses GitHub's services and privacy terms.

What stays on your machine

Atlas Tasker stores tickets as Markdown in your repository, with a local event log and rebuildable SQLite index. This marketing site cannot see or receive that project data.

The local application (Atlas Home and tracker web serve) may set one essential HttpOnly session cookie on 127.0.0.1 so the browser can talk to that loopback server. That cookie is not a tracker, is not set by this website, and is used by the loopback app. Home clears a one-time URL fragment before sending the claim to POST /session/claim; the claim is absent from request URLs and JavaScript storage.

GitHub interactions

A GitHub issue is public and is handled under GitHub's own privacy terms, so do not post private repository data there. Security reports should follow the private reporting instructions in SECURITY.md.

Deleting your data

There is no Atlas Tasker site profile or hosted project copy to delete. Remove local tracker files from your repository when you no longer want them. If Git tracks those files, they can remain in repository history until you rewrite that history.

Questions
