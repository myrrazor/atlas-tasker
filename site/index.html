Install

One binary. Start in a minute.

The installer fetches the latest release, checks its SHA-256 checksum, verifies the GitHub build attestation, and installs tracker.

Requires curl, tar, and GitHub CLI (gh) for attestation verification.

Release installer Recommended · macOS / Linux
$ curl -fsSL https://raw.githubusercontent.com/myrrazor/atlas-tasker/main/scripts/install.sh | sh
Build from source Go 1.26.4+
$ go install github.com/myrrazor/atlas-tasker/cmd/tracker@latest

Your first board From an empty repo to a groomed ticket
$ tracker init
$ tracker project create APP "My App"
$ tracker ticket create --project APP --title "Ship first feature" --type task --actor human:owner --reason "first ticket"
$ tracker board

Every write names an --actor and a --reason — that is the audit trail agents and reviewers read later. Prefer a browser? tracker web serve opens the same board as a local Kanban view.

FAQ

The sensible questions.

What is Atlas Tasker?

Atlas Tasker is a local-first issue tracker and orchestration layer that lives in your code repository. Humans and coding agents share tickets, dependencies, queues, evidence, review gates, and audit history without a hosted tracker.

What does Atlas Tasker cost?

Nothing. Atlas Tasker is MIT licensed, with no hosted service, account, or paid tier required.

Where is my data stored? Does it phone home?

Tickets are Markdown files in your repository. Changes are recorded in an append-only local event log, and SQLite provides a rebuildable query index. Atlas Tasker has no hosted mode, account system, or telemetry service.

What platforms does Atlas Tasker support?

The release installer supports macOS and Linux on arm64 and amd64. Building from source requires Go 1.26.4 or newer.

How do coding agents use it?

Run tracker mcp serve to expose typed tracker tools, or install the Codex and Claude integrations. Agents can read queues, claim tickets, dispatch runs, attach evidence, request review, acknowledge wake-ups, and hand off context.

How do I get support?

Open a GitHub issue for bugs, setup trouble, and feature requests. For a private question, email the maintainer at merlintailorcorp@gmail.com.

How do I update Atlas Tasker?

Run the curl installer again to fetch and verify the latest release. Export VERSION before running it if you need to pin a specific release.

Why not just use Jira?

Use Atlas Tasker when work should travel with a codebase and coding agents need a tool-native workflow. Jira is still a better fit when your organization needs a hosted, cross-team system with centralized administration.

How do I uninstall it?

Remove the tracker binary from your installation directory. Your project data stays in the repository until you choose to remove it.

How do I delete my data?

Delete the Atlas Tasker files from your repository. If Git tracks them, they can remain in repository history until you rewrite that history. The marketing site has no account or hosted copy of your project data to delete.
