# Atlas Tasker v1.11.0-rc1

Release candidate for the #131–#134 train (MCP workflow loop, `tracker update`, integration detect/install, local security hardening). Tag: `v1.11.0-rc1` at `fcd6cc805da39bd70e806611894e5a8c71b64208`.

## What changed

- MCP workflow profile covers the real agent loop; stdio accepts newline JSON-RPC and LSP-style `Content-Length` frames.
- `tracker update` with checksum + optional attestation verification and atomic replace.
- Integration detect / install checkboxes for Claude Code, Codex, Cursor, OpenClaw, and Grok.
- Local path-containment and private-mode hardenings; soft secret-like warnings on create/comment.
- CLI honesty fixes (same-status move no-op, nested init refusal, actor resolution, required `--type`).

## Install (pin the RC)

GitHub CLI (`gh`) is required for attestation verification.

```sh
VERSION=v1.11.0-rc1 BIN_DIR="$HOME/.local/bin" \
  sh -c 'curl -fsSL https://raw.githubusercontent.com/myrrazor/atlas-tasker/v1.11.0-rc1/scripts/install.sh | sh'
```
