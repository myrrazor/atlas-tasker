# Atlas Tasker v1.11.0-rc1

Release candidate, published 2026-09-09. Atlas is a local-first issue tracker for humans and coding agents, with Markdown tickets, an append-only event log, a rebuildable SQLite index, CLI/TUI, and an optional local browser board.

Tag commit: `fcd6cc805da39bd70e806611894e5a8c71b64208` (train #131–#134 plus release docs).

## What changed

- MCP workflow profile covers the real agent loop: create/assign/link, approve/reject/complete, agent and team management, goal brief, and wake-up list/view/ack. Stdio accepts both newline JSON-RPC and LSP-style `Content-Length` frames.
- `tracker update` self-updates from GitHub releases with checksum verification, optional `gh attestation verify`, and atomic binary replace.
- `tracker integrations detect` plus interactive install checkboxes (and `init --integrations` / `--skip-integrations`) for Claude Code, Codex, Cursor, OpenClaw, and Grok.
- Local security hardening: archive/compact path containment and symlink fail-closed checks, private modes for sensitive `.tracker` paths and config, OpenClaw `--global` destination validation, and soft secret-like warnings on ticket create/comment.
- CLI honesty fixes: same-status move is a no-op, nested init refusal, `ticket show` alias, required `--type` unless a template supplies it, and actor resolution on create/move matching claim.

## Upgrade notes

- Prefer `tracker update` once a stable release is on your `PATH`; attestation verification still needs GitHub CLI (`gh`).
- MCP clients should refresh against the workflow profile; `atlas.ticket.complete` no longer requires an operation-approval token.
- Soft secret-like warnings on create/comment are advisory; they do not block the write.

See the [full changelog](https://github.com/myrrazor/atlas-tasker/blob/v1.11.0-rc1/CHANGELOG.md) and [security limitations](https://github.com/myrrazor/atlas-tasker/blob/v1.11.0-rc1/docs/security-limitations.md).
