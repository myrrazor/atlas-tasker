# Sprint 114.0 Independent Review — Round 1 Dispositions

Round 1 of the owner's three review/fix rounds for the Sprint 114.0 gate. The independent Cursor
reviewer delivered two documents: the adapter-package report (P2 findings A–H, P3 items 1–9,
missing-test and documentation notes) and an addendum covering `internal/setup`,
`internal/contracts/managed_mode.go`, the three S0 ADRs, the acceptance tracker, the evidence page,
and the decision log (P2 findings S-A..S-D, B-A, G-A; P3 items B-B..B-H, T-A..T-C, M-A..M-C, A-A,
E-A, D-A). Both were reviewed read-only with Go overlay reproducers that never touched the source
tree. No P0 or P1 was found in either.

This page records every finding's disposition against the approved plan, the fix and regression
test where one was made, and the explicit rejections with their reasons. Decisions that change
behavior are DEC-076..DEC-080 plus revisit notes on DEC-070, DEC-073, and DEC-074 in
[../v1-decision-log.md](../v1-decision-log.md).

Disposition vocabulary: **accepted** (fixed in this round, test added), **accepted (stronger)**
(fixed with a rule stricter than the reviewer's minimum, reason given), **accepted, scheduled**
(design decision recorded now; code lands in the named ticket because it is shared service code
outside S0's scope), **accepted (docs)** (documentation-only correction), **partially accepted**,
**rejected** (reason given; the reproducer's expectation contradicts the plan or the contract's
purpose).

## 5. Explicit rejections

1. **Standalone `Command.Validate` should refuse `/usr/bin/curl` (report H, reproducer
   `TestReview_InterpreterWrappersBypassShellDenylist`, last sub-case).** Rejected. At the level of a
   bare `Command` there is no reference executable, so the only way to refuse `curl` would be a
   denylist of every program that can exfiltrate data, which is the heuristic the reviewer
   correctly criticised. The contract instead ties every command to a known executable at every
   level where one exists: plan steps and rollbacks (`Detection.ExecutablePath`), detection probes
   (the detection's own executable), verification probes (`ClientExecutable`/`ServerExecutable`).
   The reproducer's plan-level `curl` case passes; only the standalone case remains failing, by
   design. The widened denylist stays as defence in depth and `doc.go` no longer claims that
   `Validate` alone makes unsafe outcomes inexpressible.
2. **Clamp `Verification.State` to `MaxPlannedState` (report P3-4).** Rejected (DEC-078). The cap
   bounds what a plan may promise before anything runs; `Verification` reports what a post-apply
   probe proved. OpenClaw's cap is `connected_restart_required` because the saved definition and the
   live gateway differ at plan time, yet `openclaw mcp doctor --probe` opens a live session and can
   prove `connected`; clamping would report less than was observed. The gap the reviewer actually
   found (a verified result without evidence for its kind) is closed by the evidence-tie rule.
3. **Add an eleventh operation state `unverified` (addendum S-C option (a)).** Not adopted
   (DEC-079). DEC-070 pins the ten states; the distinction is carried by the integration state in
   every journal entry and report plus the run-level status vocabulary, which gives agents the
   branch they need without a second state machine.
4. **Use `--force-with-lease` for the push (addendum B-E (2)).** Rejected. Locked decision 6 and ADR
   rule 2: backup never force-pushes; a matching lease is still a force in the wire protocol and in
   server-side audit logs. The alternative the reviewer offered (state why the per-replica ref makes
   the residual race acceptable) is adopted in ADR §3.3.
5. **Reviewer fixture reusing Codex's skill path in an OpenClaw plan
   (`TestReview_OpenClawPlanCannotPromiseConnected`).** Not a rejection of the finding (A is fixed)
   but of the fixture: after finding C's stronger rule an OpenClaw plan may not write under
   `.codex/skills/`, so the reproducer fails at its own fixture. The lead's
   `TestOpenClawPlanCannotPromiseConnected` uses OpenClaw's documented `.agents/skills/atlas-worker`
   path and proves the rank fix.
