## Review and regression closeout

A GStack CSO daily diff review found no verified in-scope security vulnerability. Manual tracing covered persisted session expiry, rotation rollback, claims, origin/CSRF checks, escaped live fragments, strict MCP inputs, and bounded pagination. The ignored local report is `.gstack/security-reports/2026-10-02-pr167.json`. This AI-assisted review is not a substitute for a professional security audit.

Fresh GStack specialist and adversarial review found and fixed:

- Successful drags previously advanced revision guards on unreconciled schedule/relation and conflicting edit drafts. Those guards now retain their earlier revision.
- Queries could acquire a retired SQLite pool after the lifecycle lock was released. Operation startup now holds the lock through driver connection acquisition; rows and transactions retain active connections.
- Automatic TUI polling could start overlapping slow reloads and accept results out of order. Reloads are coalesced and superseded results are discarded.
- A sleeping tab with an evicted fingerprint could receive only event-tail changes and miss markdown-only/reindexed rows indefinitely. Unknown changed fingerprints now JSON-resync all current rows.
- Live resync restores keyboard focus on surviving tickets. Initially empty notes and acceptance overview sections refresh and clear safely.

Focused regression tests cover these triggers. Nested Codex CLI reviews were skipped because this review already ran under Codex. Fresh in-host specialists used separate contexts with the available model; no cross-model or human independence is claimed.
