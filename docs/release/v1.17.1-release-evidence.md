## Candidate regression fix

PR head `2c7e317e69f3a8efc51a3be59506e6336ecff586` failed the [macOS CI lane](https://github.com/myrrazor/atlas-tasker/actions/runs/36572870388): Linux-only `/proc/self/fd` probes returned -1 and the non-Linux `/proc/locks` stub returned zero. Assertions now apply those probes only on Linux. The replacement inode, sidecar identity/size, Python SQLite open/close storm, and fresh board/snapshot assertions still execute on macOS. Linux probes remain enforced.
