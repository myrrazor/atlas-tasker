# Atlas Tasker v1.18.2

Small fix release, 2026-10-31. No breaking changes: the CLI, JSON output and MCP tool set are unchanged, and existing workspaces need no migration.

## What changed

- **Repair copies are git-ignored** ([#191](https://github.com/myrrazor/atlas-tasker/pull/191)). `.tracker/quarantine/` is excluded from Git the same way `.tracker/web-session.json` is. `tracker init` writes the rule for new workspaces, and on an existing workspace `tracker doctor --repair` adds it once (shared mode: the managed block in `.gitignore`; private mode: `.git/info/exclude`; unmanaged mode: `.tracker/.gitignore`). Ticket files stay tracked.
- **`checksums.txt` lists bare asset names** ([#192](https://github.com/myrrazor/atlas-tasker/pull/192)). Each line is `<sha256>  <asset filename>` with no `dist/` directory, so `sha256sum -c checksums.txt` succeeds in the folder where you downloaded the assets. The installer, `scripts/verify-release.sh` and `tracker update` still accept the `dist/` lines published through v1.18.1.
- **Installer `VERSION` with or without `v`** ([#193](https://github.com/myrrazor/atlas-tasker/pull/193)). `VERSION=1.18.2` and `VERSION=v1.18.2` both install tag `v1.18.2`. A missing tag or asset exits non-zero with `atlas-tasker: release <tag> not found at <url>`. Leaving `VERSION` unset still installs the latest release.
- **Docs** ([#188](https://github.com/myrrazor/atlas-tasker/pull/188), [#189](https://github.com/myrrazor/atlas-tasker/pull/189), [#190](https://github.com/myrrazor/atlas-tasker/pull/190)). Building from source requires Go 1.26.10 or newer. The atlastasker.com hero shows the full release version, and the `tracker version --json` samples match a real release-flag binary.

## Upgrade notes

- From v1.18.1, `tracker update --yes` works. From v1.18.0 or older, reinstall with the installer or the [no-script steps](https://github.com/myrrazor/atlas-tasker/blob/v1.18.2/docs/install-without-script.md) (see the v1.18.1 notes).
- On an existing workspace, run `tracker doctor --repair` once so `.tracker/quarantine/` is ignored.

See the [full changelog](https://github.com/myrrazor/atlas-tasker/blob/v1.18.2/CHANGELOG.md).

## Install

GitHub CLI (`gh`) 2.102.0 or newer is required for attestation verification. No GitHub login is needed.

```sh
curl -fsSL https://raw.githubusercontent.com/myrrazor/atlas-tasker/v1.18.2/scripts/install.sh | sh
```

Set `BIN_DIR` for a different install location. The installer verifies checksums and GitHub build attestations before copying the binary.
