# v1.17.0 release evidence

The v1.17.0 source is commit `a3137773e87e9d53cf27d7946654a410de28334f` on `main`. It includes the code-owner-reviewed chat board [PR #165](https://github.com/myrrazor/atlas-tasker/pull/165), colored chat presentation [PR #161](https://github.com/myrrazor/atlas-tasker/pull/161), and security fixes [PR #162](https://github.com/myrrazor/atlas-tasker/pull/162) and [PR #163](https://github.com/myrrazor/atlas-tasker/pull/163). The owner requested publication on September 24, 2026.

## Local release-candidate proof

The following passed on the clean source commit with Go 1.26.6 on macOS arm64:

- `GOMAXPROCS=2 GOFLAGS=-p=2 go test -count=1 ./...`
- `GOMAXPROCS=2 GOFLAGS=-p=2 go vet ./...`
- `VERSION=v1.17.0-rc1 RUN_GOVULNCHECK=1 RUN_SBOM=1 sh scripts/preflight-release.sh`: stamped metadata matched the tag, the vulnerability check passed, and a CycloneDX SBOM was generated. Govulncheck reported zero affected code paths; it also reported two advisories in a required module that Atlas does not call.
- `VERSION=v1.17.0-rc1 sh scripts/validate-rc.sh`: version, docs links, snippets, stale strings, leakage, quickstart, terminal, MCP, parity, and performance checks passed.
- `VERSION=v1.17.0-rc1 sh scripts/release-rehearsal.sh`: the local archive verified, installed into private test state, reported the expected version and commit, and passed the packaged workflow smoke.
- `sh scripts/stability-smoke.sh`: race tests and bounded fuzz cases passed.
- The [main CI run](https://github.com/myrrazor/atlas-tasker/actions/runs/36052847184) passed workflow policy, Ubuntu, macOS, stability, and security jobs.
- The hosted-release preflight resolved the public `myrrazor/atlas-tasker` repository and the `myrrazor` actor and read the Actions workflow settings.

## Hosted release proof

Both immutable tags, `v1.17.0-rc1` and `v1.17.0`, point to the source commit above. The [hosted RC workflow](https://github.com/myrrazor/atlas-tasker/actions/runs/36054367539) and [stable workflow](https://github.com/myrrazor/atlas-tasker/actions/runs/36055293562) passed. Both releases contain four macOS/Linux amd64/arm64 archives, a CycloneDX SBOM, `checksums.txt`, and `install.sh`.

For each release, all four downloaded archives and the SBOM matched `checksums.txt`; each archive contained exactly one executable, and the published installer matched the tagged source. All four archives, the SBOM, and `checksums.txt` passed GitHub attestation verification with an empty CLI profile, bound to that tag, source commit, and the repository's release workflow. `scripts/verify-release.sh` passed on the RC macOS arm64 archive with attestation verification enabled.

The RC installer verified the published assets and installed into an empty private directory without a GitHub login. The installed binary reported the RC tag, source commit, Go 1.26.6, and macOS arm64. It passed the CLI validator, generated-skill and managed MCP checks, and an actor-separated stdio MCP workflow smoke. Those results cleared the candidate for stable publication.

For the stable release, a fresh fetch of the public, unpinned `main` installer matched tagged source byte for byte. Running it with an empty GitHub CLI profile installed `v1.17.0` into a separate private directory. `tracker version --json` reported commit `a3137773e87e9d53cf27d7946654a410de28334f`, build time `2026-09-24T20:31:07Z`, Go `1.26.6`, and `darwin/arm64`. The installed binary passed the CLI validator, generated-skill and managed MCP checks, stdio MCP workflow smoke, and a direct synthetic-workspace board smoke for HTML, Markdown, and ANSI chat output. The HTML fragment contained inline CSS, expandable cards, and the checked side-scroll control.

## Decision and limits

**Published as the latest stable release at the owner's request**, after the hosted RC and stable checks above passed. The [stable release](https://github.com/myrrazor/atlas-tasker/releases/tag/v1.17.0) carries the public downloads and verification results. The website's version copy is a separate source update and must be verified after deployment.

The written v1.17 gate also calls for a recorded GStack CSO run and human README/docs/aesthetic review. Neither was recorded for this cycle; merged PR reviews, including code-owner review of #165, and CI security checks are the available review evidence. This is a process deviation, not a claim that those checks occurred.

The new Atlas HTML board has not yet been observed in a live Meta Muse conversation. Grok Bot displayed raw HTML as text in a user test, so its guidance selects Markdown; Grok controls its message font.
