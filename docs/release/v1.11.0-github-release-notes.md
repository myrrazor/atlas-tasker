# Atlas Tasker v1.11.0

Stable release, published 2026-09-09. Atlas is a local-first issue tracker for humans and coding agents, with Markdown tickets, an append-only event log, a rebuildable SQLite index, CLI/TUI, and an optional local browser board.

## What changed

- MCP workflow profile covers the real agent loop: create/assign/link, approve/reject/complete, agent and team management, goal brief, and wake-up list/view/ack. Stdio accepts both newline JSON-RPC and LSP-style `Content-Length` frames.
- `tracker update` self-updates from GitHub releases with checksum verification, optional `gh attestation verify`, and atomic binary replace.
- `tracker integrations detect` plus interactive install checkboxes (and `init --integrations` / `--skip-integrations`) for Claude Code, Codex, Cursor, OpenClaw, and Grok.
- Local security hardening: archive/compact path containment and symlink fail-closed checks, private modes for sensitive `.tracker` paths and config, OpenClaw `--global` destination validation, and soft secret-like warnings on ticket create/comment.
- CLI honesty fixes: same-status move is a no-op, nested init refusal, `ticket show` alias, required `--type` unless a template supplies it, and actor resolution on create/move matching claim.

## Upgrade notes

- Prefer `tracker update` once this release is on your `PATH`; attestation verification still needs GitHub CLI (`gh`).
- MCP clients that only exposed the older workflow tool set should refresh against the workflow profile; `atlas.ticket.complete` no longer requires an operation-approval token.
- Open completion mode can complete from `in_progress` without the three-step review path when that policy is enabled.
- Soft secret-like warnings on create/comment are advisory; they do not block the write.

See the [full changelog](https://github.com/myrrazor/atlas-tasker/blob/v1.11.0/CHANGELOG.md) and [security limitations](https://github.com/myrrazor/atlas-tasker/blob/v1.11.0/docs/security-limitations.md).

## Install

GitHub CLI (`gh`) is required for artifact attestation verification.

```sh
curl -fsSL https://raw.githubusercontent.com/myrrazor/atlas-tasker/v1.11.0/scripts/install.sh | sh
```

Set `BIN_DIR` when a different install location is needed. The installer verifies checksums and GitHub build attestations before copying the binary. Existing installs can run `tracker update --yes`.
