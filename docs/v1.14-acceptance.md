# Atlas Tasker v1.14 Acceptance Tracker

Ticket-by-ticket status for the 45 units of the
[v1.14 implementation plan](v1.14-implementation-plan.md). AT114 IDs are plan IDs, not GitHub
issue numbers. "Result" records what was actually observed (test output, behavior), never what is
expected. Full sanitized gate output for each sprint is committed as `TEST_STDOUT.log` on the branch
(the repository's existing convention) and summarized in
[docs/release/v1.14-baseline-evidence.md](release/v1.14-baseline-evidence.md).

Status values: `done` (reviewed evidence recorded), `implemented` (evidence recorded, awaiting
independent review), `in_progress`, `not_started`, `blocked`.
