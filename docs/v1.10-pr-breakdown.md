# Atlas Tasker v1.10 PR Breakdown

## WEB-901 - Contracts, Command Surface, Security Freeze

- Add `tracker web` command family.
- Document local-only security model.
- Add `EventSurfaceWeb`.

## WEB-902 - Web Server Core

- Add `internal/web`.
- Serve embedded templates and static assets.
- Enforce token/session, CSRF, Origin/Referer checks, security headers, no CORS.
- Write non-secret runtime status to `.tracker/runtime/web/server.json`.

## WEB-903 - Read-Only Board

- Render the Kanban board from `QueryService.Board`.
- Render ticket detail from `QueryService.TicketDetail`.
- Escape all ticket fields, comments, labels, actors, and history text.

## WEB-904 - Safe Mutations

- Add forms and handlers for create, edit, comment, move, request review, approve, complete, assign, and labels.
- Every mutation calls `ActionService` and records `surface: "web"`.
- Read-only mode rejects all mutations.

## WEB-905 - Drag/Drop

- Vendor `sortablejs@1.15.7` under `internal/web/static/vendor/`.
- Cross-column drag posts to existing move endpoints.
- Intra-column ordering is deferred and snaps back to service order.

## WEB-906 - Filters And Views

- Support project, assignee, type, status/column, reviewer, label, priority, text search, and saved board views.
- Keep filter state in the URL.

## WEB-907 - Visual Polish

- Implement the approved minimal dark Atlas design.
- Provide responsive board behavior and a mobile detail sheet.
- Add keyboard/button fallback and visible focus states.

## WEB-908 - Release Proof

- Add docs and smoke coverage.
- Refresh `TEST_STDOUT.log`.
- Validate with full Go tests, vet, stability smoke, and release rehearsal.
